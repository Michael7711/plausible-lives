# Project Overview

## Objective

Investigate AI-assisted constraint-based modelling of
plausible human lives.

## Current Research Questions

1. How can aspects of a person's life be represented
   using structured data?

2. How can constraints distinguish plausible scenarios
   from invalid scenarios?

3. Can AI generate large amounts of structured content?

4. Can AI generate constraints for possible lives?

5. Can AI identify and repair invalid WorkSpecs?

6. How can differences between plausible lives be
   interpreted as choices?

## Initial Approach

Explore Universal Automation Wiki and WorkSpec.

Experiment with both the visual interface and CLI.

Investigate constraint validation before developing
our own automated generation and repair system.
